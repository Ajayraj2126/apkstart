Install Android to a Virtual Disk

The virtual machine window is open. Complete the six steps below once. ApkStart will then boot directly from the virtual disk.

  1. Boot menu: select Installation - Install Android-x86 to harddisk using ↓ and press Enter
  2. Choose Partition: select Create/Modify partitions; choose No when asked about GPT
  3. cfdisk partitioning: choose New → Primary → Enter for size → Bootable → Write → type yes → Quit
  4. Format: select vda1, choose ext4, then Yes
  5. Bootloader and system: select Yes for Install GRUB and Install /system as read-write
  6. Finish: after installation reaches 100%, click "Installation Complete" below; ApkStart will reboot and take over

If adb remains disconnected, press Ctrl+Alt+F1 in the VM window and run setprop service.adb.tcp.port 5555、stop adbd、start adbd， Then press Ctrl+Alt+F7 to return to the graphical interface.

本机体检 · 自动配置
先查一遍这台机器：CPU 虚拟化有没有开、Windows 的虚拟机监控程序平台在不在、 显卡是什么、显存多大、内存和系统版本够不够。能自动改的（内存 / 核心 / 画质 / 渲染后端）直接写进设置， 并把结果固化成一份驱动；必须管理员权限的给按钮；只能在 BIOS 里改的会告诉你怎么改。
驱动 · 兼容补丁
有些机器要改启动参数才跑得起来（老显卡 GLES 版本低、没开硬件加速、某版驱动一开硬件渲染就崩）。 驱动就是一份 JSON：声明「匹配哪些机器」+「命中后改哪些启动参数」。你可以自己写、导入、分享。 驱动只改白名单里的启动项，不执行任何代码；匹配不上就不生效。
